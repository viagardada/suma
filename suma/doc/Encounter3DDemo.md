# 双机相遇三维演示

双击 `suma/run_encounter_3d.bat`，或运行 `python suma/encounter_3d_demo.py`。
需要 Python、NumPy、Matplotlib；导出 GIF 使用 Pillow，均已在当前 Anaconda 中安装。
无须启动 Julia，建议来自最新 `my_lightweight_table_dense.csv` 的精确九维查表。

默认场景：本机从 `(0,0,1000)` 向 `(0,10000,1000)` 沿直线飞行，入侵者从
`(0,6000,1000)` 反向飞行，两机水平速度均为 200 ft/s。实际本机忽略全部建议，
15 秒时两机实际位置重合。本演示保留这种对照，不会悄悄让实线本机执行避让。

- 蓝色实线/蓝色飞机：实际本机，达到目的地后停留。
- 红色实线/红色飞机：实际入侵者，持续直飞；远离显示范围后隐藏图标。
- 绿色虚线/空心标记：假如本机执行首次有效建议后的轨迹与位置，并非第三架飞机。
- 绿色菱形：接回原直线航线的位置；黄色星形：目的地。

虚线按首次有效 H/V 建议的左右和升降方向生成，经历避让、保持、归航、继续到目的地。
五次多项式使偏移及其一、二阶导数在衔接点连续；归航接入时横向偏移和高度偏移为 0，
航向与垂直速度也与原航线一致。归航点位于目的地之前；绕行后到达时间通常晚于实飞。
为了遵守机动上限，假想轨迹可减速；本机实际速度始终不受影响。

首次有效避让建议出现时，一次性确定避让、保持、相切归航及到达目的地的完整路线。
规划比较保持距离（300、700、1100 ft）和归航距离
（1200、1800、2400、3200 ft），筛除不满足间隔或无法在目的地前至少 600 ft 接回的方案。
有转弯建议时横向偏移固定为 30 m（约 98.43 ft）。
在满足完整路线间隔和机动限制的候选中比较到达时间和路程；这是候选集合内择优。
有升降建议时垂直偏移固定为 10 m（约 32.81 ft）。
为配合该演示幅度，水平间隔门槛采用 25 m，保留 10% 余量；垂直门槛仍为 100 ft。
接回点的偏移及一、二阶导数为零，保证与原航线相切且曲率平滑衔接。

完整路线选定后全程固定，接入点也保持固定。播放、暂停、拖动时间和后续查表结果
均不会改变路线。`report.json` 的 `planning_runs` 为 1，并记录候选数、选择标准和接入点。
当前选择标准为横向偏移、垂直偏移、到达时间与路程，尚未加入能耗优化。

运动学上限默认：水平速度 200 ft/s、航向变化率 3 deg/s、垂直率 16.667 ft/s。
整条假想轨迹（含归航段）按 0.025 秒检查：水平间距≥25 m 或垂直间距≥100 ft，
并留出至少 10% 的归一化余量。这是演示采用的检查条件，不是 ACAS 告警阈值。
轨迹由本程序规划，不是 sUMA 直接输出的轨迹；没有模拟气动力、加速度或飞控响应。
三维坐标以 ft 标注，坐标轴的视觉比例为展示效果调整，飞机符号也有放大。
三维视图默认放大，横向与高度显示范围随选定路线收紧，以便看清小幅避让动作。

实际支路持续查表，后续建议可能变化；假想支路的初始避让方向来自第一次有效机动，
随后沿一次确定的路线归航，不随实际支路的建议重置轨迹。缺失记录显示“无匹配记录”，
不当作 H:0|V:0。位置重合时不伪造方位。

交互：播放/暂停、重置、倍速、时间滑块；空格切换播放，左右键步进，R 重置。
拖动三维视图可以旋转，缩放使用 Matplotlib 三维视图默认操作。

```powershell
python suma/encounter_3d_demo.py --snapshot suma/output/encounter_3d/preview.png --snapshot-time 15 --no-gui
python suma/encounter_3d_demo.py --gif suma/output/encounter_3d/demo.gif --fps 10 --playback 4 --no-gui
python suma/test_encounter_3d_demo.py -v
```

运行后在 `suma/output/encounter_3d/` 保存 `report.json` 和 `trajectory.csv`，包含建议来源、
首次建议时刻、两支路最小间距、归航点、到达时间及逐时刻位置。调整速度后如果查不到
有效建议，或无法在限幅和间隔条件下找到路线，程序会明确报错，不会画未经检查的虚线。
